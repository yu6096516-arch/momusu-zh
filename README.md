# 魔物娘TD 完整汉化

《モンスター娘TD（魔物娘TDX）》PC 版的**中文汉化**，主界面图片ui未汉化（施工中）

---

## 怎么装

**方式一：下发行包

到 [Releases](https://github.com/yu6096516-arch/momusu-zh/releases/tag/v1.1) 下载 `MonmusuTD_zh-Hans_v1.1.zip`（59.5 MB），
把里面的 `BepInEx` 文件夹覆盖到游戏根目录即可（已含插件、译文、字体、配置）。

**方式二：只用仓库译文**

1. 先装好 **BepInEx**（IL2CPP 版）到游戏根目录
2. 把本仓库 `translations` 整个文件夹放进：

```
<游戏根目录>\BepInEx\plugins\MonsterMusumeTDMod\translations\
```

3. 需要 **MonsterMusumeTDMod.dll**（汉化插件本体，不在本仓库）
4. 启动游戏即生效

> 插件源码在仓库 `source/`，二进制请到原作者处获取：`Berumic/MomusuMod-Android-workflow`

---

## 怎么用

| 操作 | 效果 |
|---|---|
| 启动游戏 | 自动加载中文 |
| 按 **F6** | 手动重载/同步译文（改完文件不用重启） |
| 按 **F8** | 导出当前界面的文本快照（排查漏翻用） |

配置文件 `BepInEx\config\MonsterMusumeTDMod.cfg`：

```ini
[Translation]
Enabled = true

[Translation.Font]
FontAssetPath = alimama      # 中文用这套字体

[Translation.Update]
Enabled = false              # 自动更新：建议关，别让它覆盖本地
ManualSyncWithF6 = false     # F6 只重载本地
```

> ⚠️ `AssetBaseUrl` 一定留空——否则插件会去下载原版字体，把补好字形的字体覆盖回去。

## 译文维护（以后新特性怎么办）

游戏会先解析正文里的标记、算出方括号里的数值，再交给 UI：

| 标记 | 觉醒单位显示 | 未觉醒单位显示 |
|---|---|---|
| `[awaked,X]` | `X` | 整段去掉 |
| `[notawaked,Y]` | 整段去掉 | `Y` |

数值表达式同理：`[MAG,0,0]`、`[0,2,0]`、`[duration]`、`[attack,[MAG,0,0]]` 在运行时都会变成真实数字（例如「再出撃時間[0,2,0]%短縮」→「再出撃時間40%短縮」）。

词库只存"未解析"的原始形态，而插件是按运行时字符串做匹配的，所以**新特性只要带分支标记或数值表达式，就必须同时存一份解析后形态**，否则又会回退日文。另外特性标题「種族特性：XXX」也要单独成键。

仓库里有两个脚本 + 一个批处理把这件事自动化了：

| 文件 | 作用 |
|---|---|
| `tools\生成解析后形态词条.py` | 扫描 `UICanvas` 全库，重建 `translations/UICanvas/_awaked/zh_Hans.json`：分支形态（觉醒/未觉醒各一份）、数值形态（方括号→插件 `<num>` 占位符，走数字模板匹配）、特性标题（按 `ability_data` 的特性名表批量生成 `種族特性：XXX`）。当前 3,611 条。幂等，可反复执行；`--check` 只体检不写文件 |
| `tools\同步译文到仓库.py` | 游戏目录 → 仓库 `translations\` 全量同步（含删除上游已移除的文件），并重建 `manifest.json` |
| `publish_update.bat` | 一键三步：生成解析后形态词条 → 同步译文树 → `git add/commit/push` |

**以后游戏更新、译文更新后的流程**：把新译文放进游戏目录 → 双击 `publish_update.bat` → 推送完成。用户端启动游戏或按 F6 自动更新。

> 注意：F6 只重载词表；**已经渲染出来的文本要切换单位/重开界面才会重新翻译**（插件按控件缓存了处理结果）。验证新词条时记得先切一下。

**验收口径**：`生成解析后形态词条.py --check` 的输出参考

```
译文条目: 131624（去重 62802） 读取失败: 0
  + 分支标记形态: 843
  + 数值占位符形态: 776
  + 特性标题: 1992
  新增合计: 3611（已存在跳过 25）
```

条目数随游戏更新会涨；关键是 `读取失败: 0`，以及特性标题数 ≈ 特性名表里 `值 != 键` 的条目数（说明新特性也拿到标题了）。
