## 三、译文质量口径（节选，全量见 DECISIONS.md）

### 3.1 硬约束（每批校验）
- 键逐字不动；**值行数必须＝键行数**
- **标签只能从键里逐行抄**（`<interval=>`／`<size=>`／`<ruby=>` 不得静默增删、不得挪行）
- 值内禁：半角 `~`／`...`／假名残留（含 U+309B、゛）／弯引号 `“”‘’`／`《》`／U+2015（改 U+2014）／半角字母数字
- 键尾标点＝值尾标点（`――。`→`——。`；`――、`→`——，`）

### 3.2 引号体系
| 类型 | 值内 |
|---|---|
| 术语／道具／技名／组织名／章节·条目名 | 『』 |
| 台词内嵌引语／信件／字条／神签／自我引述／暗号／转述／歌谣／齐喊 | 「」 |
| 通讯块定界（`”…`／键尾 `"`） | 「」开＝行首、闭＝键尾 |
| 拟声／效果音 | 『』 |
| 校名｜地名·村名 | 键带「」→『』，裸键裸写｜随键用「」 |

### 3.3 说话人分档（同一假名按角色拆译，禁批量替换）
- `ご主人くん`：琳／劳伦等 → **主人**（不加君）；铃 → **主人君**
- `アタシ`／`アタイ`：莉歌拉娜 → **人家**；筋肉娘 → **老娘**；トルス系等 → **我**；偷猎者 → 我
- `お姉ちゃん`：**铃专用**；T.O.W.E.R. 四姐妹、女忍者等其他角色各自处理
- 「您」：主仆／尊卑敬称保留；同辈敬体改「你」（按弧分档，同一文件可两档并存）

### 3.4 语尾口癖
| 原文 | 落地 |
|---|---|
| っす（マズル） | 的说（っすよ→的说哟） |
| デス（リトルグレイ／プピペルザ／ピペリ／ピンダ／ワタクシ系） | 的说（デスネ→的说呢；**デスガ 不落**） |
| でし（スクラティ） | 的说 |
| であります（巴乌） | 的说（陈述/请求句补，疑问与句中不补） |
| だち／でち（ヤノ） | **哒嘁**（≠でし） |
| です／ですぅ／ですの | **一律不落「的说」**；ですの→呢、ですぅ→拖音 |
| ですぞ／であるぞよ | 自然语尾（哦／呢／哟） |
| ざます | 自称本小姐，语尾不译 |
| ンダモン | **哒蒙**（モォン→哞、モ゛フ→哞呜） |
| ぶー族 | 语尾→噗／一人称→咱 |
| じゃん | **嘛（罗蒂专属）**；まぁ／もの／もん 的「嘛」合法不动 |

## 四、工具盲区与对策（本项目最大收获）

`qc_act.py` 与 `sweep.py` 是双引擎，但 258 批实战中确认存在**四类两者都不报**的缺陷，已全部改为「自写脚本必检」：

| # | 盲区 | 表现 | 对策 |
|---|---|---|---|
| 1 | **行压缩良性档** | 行数不足且单行 ≤28 字时，qc 只报 WARN、sweep 不报 | 「行压缩」WARN 一律当必查，**整段前半被吞就藏在这里** |
| 2 | **键内全角空格（U+3000）** | 键有值无，两引擎皆 0 报（单批最高 24 处） | 自写「逐行全角空格数目同构」断言（中段必对齐，键尾空格不必回填） |
| 3 | **键尾句读 × 值尾句读** | `――。` 值只剩「——」，连**扁平定稿版自身**也漏约 2% | 逐键比对键尾/值尾标点 |
| 4 | **键非空而值为空** | 值＝纯空格或整篇空串，早期 sweep 不报 | 加「值 strip 后为空」检查；255 批 sweep 终于报出 393 项 |

另有两条工具行为必须记住：
- **`patcher_act.apply` 每次调用覆盖 `diff_<file>.txt`** → 分小段 apply 必丢日志，**批末必须按 backup 基线全量重建 diff**
- **qc 报「标签不一致」不给键名** → 必须自写逐行位次脚本定位（常与「看起来最像」的那条无关）

## 五、项目级重大发现

1. **同一事件存在两份副本**：`活动\<名>`（扁平，可能已定稿）与 `活动\<弧目录>\<名>`（弧目录，常为旧机译或整篇空值）。键数一致可**按键文本（不是索引）逐键随入**；键数不一致须顺序走查＋断点断言重接。**随入后仍要补做键尾句读核对。**
2. **`backup_活动` 镜像了弧目录结构**：基线必须是 `backup_活动\<弧目录>\…`，误用扁平基线会把 diff 算错（实测 186 → 69）。
3. **「已定稿」不等于「零缺陷」**：定稿文件里仍查出性别判反（丰提小姐）、自称错档、命令对象译反、键尾句读漏句、空值等问题共数十处——**定稿只代表「比旧译可靠」，不代表免检**。
4. **人名／术语连坐**：`ギュラ`（奇拉）与 `シンギュラリティ`（奇点）必须两截不同字（「奇拉……不，奇点」才有纠正笑点）；`比基喵 − 比基 = 喵` 这类拆字梗必须在中文能成立；`메ンコ` 类绰号必须与全名可回指。

## 六、跨键接缝病（258 批累计抓出最多的隐性错误）

双引擎全放过、只能**全文拼接通读**发现，已定型 12 类：

接缝同字重复（「真真是的」「可不过」）｜前缀/宾语被译两遍（「下一个下一个世界」）｜前键末字被吞｜跨键行序错位｜跨键首音被当词（`ご｜にょごにょ` 的「ご」≠「主」）｜拆键拟声丢音节｜`っ`+interval 位置错（interval 应落**后键行首**、促音不译）｜键尾悬空假名未让给下一键｜拆键人名只改前半截｜数字悬空｜断词歧义（`こそこそ` 被断成「そこ／そこ」）｜命令对象/修饰关系译反（`猫耳だから`＝我有猫耳≠我是猫耳）

> 结论：**「两个工具都放过」不等于「没有问题」，只等于「它长得不难看」。** 通读不可省。
